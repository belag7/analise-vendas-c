# 📊 Sistema de Análise de Vendas Diárias

> Projeto desenvolvido para simulação do controle e análise do fluxo de vendas diárias em um estabelecimento comercial.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação em **C** desenvolvida para registrar e processar os dados de vendas ao longo de um período de 5 dias. 

O sistema permite a entrada contínua de dados do usuário, calcula a soma acumulada de vendas e gera um relatório detalhado com a quantidade vendida em cada dia e a quantidade total do período.

---

## 🚀 Tecnologias e Conceitos Aplicados

* **Linguagem:** C
* **Estruturas de Dados:** Vetores (*Arrays*) para armazenamento sequencial dos dados diários.
* **Estruturas de Repetição:** Laço `for` para entrada e varredura de dados.
* **Lógica de Programação:** Acumuladores e formatação de saída no terminal.
